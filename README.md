# Ravon — R harfi talaffuz mashqlari

O‘zbekcha **R** tovushini to‘g‘rilash uchun bosqichma-bosqich mashqlar.

## Online

- **Cloudflare Pages:** https://ravon-9m4.pages.dev
- **GitHub:** https://github.com/AbduraximSHER/ravon

## Lokal ishga tushirish

```bash
npm install
npm run dev
```

Brauzerda `http://localhost:3847`.

## Deploy (Cloudflare Pages)

```bash
npm run build
npx wrangler pages deploy out --project-name=ravon
```

Static export (`out/`) Cloudflare Pages’ga yuklanadi.

## Eslatma

Uy mashqlari uchun. Jiddiy nutq qiyinchiligi bo‘lsa, logopedga murojaat qiling.
